# Featured Projects

## RetainIQ

### AI-Based Customer Churn Prediction & Retention Analytics Platform

An end-to-end ML platform for predicting customer churn and supporting data-driven retention decisions.

**Tech Stack**

`Python` `scikit-learn` `XGBoost` `SHAP` `FastAPI` `Next.js` `PostgreSQL` `Supabase` `Docker`

**Highlights**

- Built an ML pipeline using the **IBM Telco Customer Churn dataset** containing **7,043 records and 21 features**.
- Benchmarked **Logistic Regression, Random Forest, and XGBoost** models.
- Selected Logistic Regression with a **ROC-AUC of 84.59%** based on model evaluation.
- Integrated **SHAP** for model interpretability and feature-level explanations.
- Developed a **FastAPI inference service** for real-time churn probability prediction.
- Connected the backend with a **Next.js 14** frontend and persisted predictions using **Supabase PostgreSQL**.
- Implemented a **Revenue Impact Calculator** and downloadable PDF reports.
- Containerized the application using **Docker** and deployed the application stack using Vercel and Render.

# Research

## ASTRA Lab · IIT Madras

### Binary-Level Program Analysis & Indirect Call Target Refinement

Research work focused on improving the precision of **indirect call target identification at the binary level**, particularly for stripped binaries where source-level information, symbols, and type information are unavailable.

**Research Areas**

`Control-Flow Integrity` · `Value Set Analysis` · `Block-Based Points-to Analysis` · `MBA-IR` · `SSA` · `Value Tracking`

**Work includes**

- Studying challenges in recovering precise control-flow information from stripped binaries.
- Investigating limitations of **Value Set Analysis**, particularly scalability and over-approximation.
- Exploring **Block-Based Points-to Analysis (BPA)** and block-oriented memory modeling.
- Working with **MBA-IR and SSA representations** for binary analysis.
- Studying value tracking and iterative/fixed-point refinement.
- Examining the dependency between **value analysis and control-flow reconstruction** when resolving indirect call targets.
