## `RESEARCH`

### ASTRA Lab · IIT Madras

**Refining Indirect Call Targets at the Binary Level**

<br>

<img src="https://img.shields.io/badge/BINARY%20ANALYSIS-1D4ED8?style=flat-square"/>
<img src="https://img.shields.io/badge/CONTROL--FLOW%20INTEGRITY-4338CA?style=flat-square"/>
<img src="https://img.shields.io/badge/POINTS--TO%20ANALYSIS-6D28D9?style=flat-square"/>
<img src="https://img.shields.io/badge/SSA-7C3AED?style=flat-square"/>

</div>

<br>

<table>
<tr>
<td width="48%" valign="top">

### The Problem

Stripped binaries often lack source code, symbols, and type information, making precise **control-flow reconstruction** difficult.

Indirect calls create an additional challenge: accurate value information is needed to determine possible targets, while those targets are themselves required to refine the control-flow graph.

</td>

<td width="52%" valign="top">

### The Approach

Explored **Block-Based Points-to Analysis (BPA)** with:

`Block Memory Model`
`MBA-IR`
`SSA Conversion`
`Value Tracking`
`Iterative / Fixed-Point Refinement`

The work investigates how value analysis can help refine indirect call targets and improve binary-level CFG precision.

</td>
</tr>
</table>
