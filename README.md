### RetainIQ

**AI-based customer churn prediction and retention analytics platform**

End-to-end ML application built on the IBM Telco Customer Churn dataset (7,043 records, 21 features), covering preprocessing, model selection, explainability, and deployment.

**Stack:** `Python` `XGBoost` `scikit-learn` `SHAP` `FastAPI` `Next.js 14` `PostgreSQL / Supabase` `Docker`

## Research

### Binary-Level Program Analysis — IIT Madras

**Refining indirect call targets at the binary level (Block-based Points-to Analysis)**

Continuing research work under Prof. Narayanaswamy N. S., Department of CSE, IIT Madras, on resolving indirect call targets in stripped binaries. The work analyzes the Nginx 1.28.0 binary — both with debug info and stripped — using Ghidra for function recovery and control-flow graph analysis. The current phase extends into indirect call identification, function pointer tracking, and Block-based Points-to Analysis for call-edge refinement.
